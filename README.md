# Balltze

## Notice

Due to Chimera taking most of the features that Balltze was supposed to have on its next 
release, the development of this version of Balltze has been discontinued. This repository will 
remain public with the latest release available, but no new features or bug fixes will be added 
to it (unless is required for Insurrection); if you want to use it, you will need Chimera 
v1.0.0-r1042 or older, because newer versions are not compatible. If you want to use newer 
Chimera versions, unfortunately this mod won't work for you.

A new version of Balltze is planned for the future, which will be a rewrite of the mod and 
unfortunately will not be compatible with Chimera. It won't contain any piece of GPL-3 code 
from Chimera or other projects, so it likely won't be open source, but it will be available for 
free and will have a lot of new features and improvements over the current version.

If you're interested in the Balltze rewrite and want to be updated about it or test some beta 
builds when the time comes, join the [Discord server](https://discord.gg/SaNrgyftr6) and stay 
tuned for announcements! 🙂

Hopefully, by the time someone reads this, the Discord server will be up and running LOL.

## Installation
1. [Install Chimera v1.0.0-r1042](https://github.com/SnowyMouse/chimera#installation).
2. Create a folder called "mods" (e.g. "D:\Halo Custom Edition\mods").
3. Grab the latest release from the [releases page](https://github.com/MangoFizz/balltze/releases/latest).
4. Copy balltze.dll file to your mods folder.
5. Copy the contents of the "data" folder to your "My Games\Halo CE" folder.
6. Launch the game for the first time after installing Balltze.
